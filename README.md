# Mateusz Hoffman - Personal Website & Digital Business Card

Welcome to the source code of my personal website, available at [mateuszhoffman.com](https://mateuszhoffman.com).

This repository serves as my digital business card and showcasing my professional experience.

## Technical Details

While this site exists primarily to host my unified profile and resume, it's built with modern web technologies:

- **Framework:** React 18 built with Vite
- **Architecture:** Single-page application with a dynamic, state-driven view stack
- **Styling:** Custom CSS with a focus on polished typography, responsive layouts, and subtle animations
- **Content:** Driven by structured data (`src/data/resumeData.js`) for easy maintainability
- **Deployment:** Configured for seamless automated delivery via Netlify (`netlify.toml`)

## Local Development

If you'd like to run it locally:

```bash
npm install
npm run dev
```

The site will be available at `http://localhost:5173`.
